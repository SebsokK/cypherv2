# Asset licenses

## Project presentation assets

This release includes runtime presentation assets under `assets/`, including system artwork, default document icons, the pause/turn-marker presentation, the no-Scene lobby background, and README screenshots. The repository currently treats these as project-specific assets, but does not yet record asset-by-asset authorship, source URL, license, required attribution, and review date.

## Third-party and rules content

No legacy Cypher System icon identified in `THIRD-PARTY-NOTICES.md` is represented as having been copied into these runtime assets.

No runtime image is currently documented here as a known third-party asset with its own license. Monte Cook Games rules content and its Cypher Open License basis are documented separately in `CONTENT-SOURCES.md`; that content license is not presented as an image-asset license.

## Outstanding provenance record

The missing asset-by-asset provenance details must be supplied before making any more specific public licensing claim about these images. The repository does not identify any of the current runtime images as copied legacy or CRD artwork, but this notice does not manufacture or substitute for a complete provenance record.

Future assets must record the file path, author, source URL, license, required attribution, and date reviewed.
